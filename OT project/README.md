# Clockwork: multi-objective college timetable optimisation

Clash-free college timetables that trade off three objectives:

- **f1, idle gaps:** free periods between classes, for students and staff
- **f2, room wastage:** unused seats in the assigned rooms
- **f3, workload imbalance:** how unevenly teaching load is spread across faculty

The main method is a **memetic NSGA-II**: NSGA-II plus seeding, repair and local search. It is compared against a Greedy/DSatur baseline and random search.

All instances are **synthetic** (generated by `src/instance_generator.py`). Results are not measurements of any real institute.

## Running it

You need Python 3.11+ and Node 18+. Install once:

```bash
pip install -r requirements.txt
cd frontend && npm install
```

Start the two servers in two terminals, from the project folder:

```bash
python -m uvicorn api.server:app --port 8000
```

```bash
npm --prefix frontend run dev
```

Open http://localhost:5173 and press **Run optimiser** on the Overview page. Without the Python server the website still works, using built-in demo data.

### Command line (no website)

```bash
python main.py --scenario medium --generations 40 --seed 1
python main.py --scenario small --no-repair --no-local-search   # ablation variant
```

The full result is saved to `results/<scenario>_i<instance seed>_s<seed>.json`.

### Experiments (proposal Section 13)

```bash
python -m experiments.run_experiments --scenarios small medium --seeds 30 --cpsat
python -m experiments.run_experiments --methods ablation --scenarios medium --seeds 30
python -m experiments.run_experiments --scenarios small --seeds 3 --budget 600 --name quick   # 15-second check
```

Every stochastic method gets the same evaluation budget (3000 by default, 1500 for Large) and the same
seeds 1..N, run in parallel. Greedy runs once. CP-SAT runs once per instance, alone, with a time limit per
weight vector (20 s Small, 60 s Medium, 120 s Large). Output goes to `results/experiments/<name>/`:

- `summary.md` / `summary.csv`: hypervolume mean ± sd and median, Wilcoxon rank-sum p and Vargha-Delaney
  A12 against NSGA-II, front size, spacing, best value of each objective, feasibility rate, run time,
  plus CP-SAT status and optimality gap
- `runs.csv`: one row per run; `fronts.json`: every returned front
- `figures/`: hypervolume box plots, Pareto projections, 3-D fronts, convergence curves

| Method (`--methods` name) | What it is |
|---|---|
| `greedy` | Greedy / DSatur baseline |
| `random_search` | random timetables made feasible by repair |
| `weighted_ga` | single-objective GA, 7 weight vectors, same operators as NSGA-II |
| `simulated_annealing` | weighted-sum SA from the greedy timetable, 7 weight vectors |
| `nsga3` | NSGA-III (reference directions + niching), same operators and hybrids |
| `nsga2` | memetic NSGA-II (the main method) |
| `cpsat` | exact CP-SAT model of C1-C8, weighted sum (f3 as max-min load spread), via `--cpsat` |
| `nsga2_plain`, `nsga2_seed`, `nsga2_repair`, `nsga2_ls`, `nsga2_seed_repair` | ablation variants (`--methods ablation`) |

### Tests

python -m tests.test_core

## Layout (proposal Section 17)

```
main.py                     CLI entry point
api/server.py               FastAPI server for the website (background runs + progress)
src/problem.py              entities, indexed problem, chromosome (slot, room per event; teacher per offering)
src/instance_generator.py   demo / small / medium / large synthetic instances
src/evaluator.py            f1, f2, f3, violation V(s) for C2-C8, practical metrics
src/schedule_state.py       incremental occupancy used by greedy, repair and local search
src/runner.py               one full run -> JSON (shared by CLI and API)
src/baseline/               greedy_dsatur.py, random_search.py, simulated_annealing.py
src/algorithms/             nsga2.py, nsga3.py, weighted_ga.py, cpsat_reference.py, scalarise.py
src/methods.py              every method behind one interface (same budget, same output)
experiments/run_experiments.py   repeated seeded runs, statistics, figures
src/multiobjective/         non_dominated_sort.py, hypervolume.py (exact 3-D HV, spacing)
src/hybrid/                 seeding.py, repair.py, local_search.py
tests/                      formula, constraint and method checks
frontend/                   Clockwork website (React + Vite + TypeScript)
```
